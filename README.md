# NEXTCODE ACADEMY

AI와 웹 개발 교육과정을 소개하는 가상의 IT 전문 교육기관 반응형 홍보 홈페이지입니다.

## 제작 목적

AI를 활용한 바이브 코딩 실습 평가 과제로, 전문 교육기관의 신뢰감과 현대적인 개발자 부트캠프 스타일을 결합해 구현했습니다. 실제 기관이나 수강생의 정보는 사용하지 않았습니다.

## 사용 기술

- HTML5
- CSS3
- Vanilla JavaScript
- 별도 프레임워크, 패키지 설치, 빌드 과정 없음

## 주요 기능

- AI 서비스 개발, 풀스택 웹 개발 교육과정 소개
- 프로젝트 예시와 과정 상세 정보 연결
- 데스크톱, 태블릿, 모바일 반응형 레이아웃
- 고정 헤더와 스크롤 상태 변화
- 모바일 햄버거 메뉴와 닫기 기능
- 부드러운 내부 이동 및 실제 섹션으로 연결되는 모든 버튼
- 키보드 포커스, 본문 바로가기, 시맨틱 마크업 등 기본 접근성
- 모션 감소 사용자 환경 지원

## 실행 방법

1. 저장소를 내려받거나 압축 파일을 풉니다.
2. `index.html` 파일을 브라우저에서 직접 엽니다.

별도 설치, 빌드, 서버 실행 없이 사용할 수 있습니다.

## 바이브 코딩 활용 내용

요구사항 분석, 정보 구조 설계, 반응형 UI 구현, 접근성 고려, 내부 링크 및 모바일 메뉴 동작 구현, 정적 코드 검토와 브라우저 검증 과정에 AI 코딩 도구를 활용했습니다. 생성된 결과는 요구사항과 실제 동작을 기준으로 점검하는 것을 원칙으로 합니다.
